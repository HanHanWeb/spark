# Spark · 便签速记

搜索框即入口的轻量便签速记工具。多工作区数据隔离，支持账号登录与云端同步，灵感、待办、想法与日记随手捕捉。

## 功能特性

- **速记即所得**：搜索框直接输入，回车保存；分类随选，标签着色
- **多工作区**：工作区之间相互隔离，各自独立的分类与便签，可随时切换
- **完成态**：便签可标记为已完成（划线弱化显示），状态跨设备同步
- **优先级**：新增高 / 中 / 低三级，淡红到深红渐变区分；添加时通过胶囊选择器设定，后续点击胶囊可循环切换
- **双视图**：列表与 Kanban 看板一键切换（视图按工作区记忆）。看板按分类分列，网格一行 4 个自动换行，拖拽改分类与排序，逐块淡入
- **分类切换动效**：列表分类切换按左右顺序滑入（`slide-in-from-left/right`），符合导航逻辑
- **胶囊搜索框 + Border Beam**：`h-11 rounded-full` 胶囊输入框，集成 `border-beam` 流光边框，支持 4 种配色（colorful/ocean/sunset/mono）与开关，速度可调（快 2s / 默认 3s / 慢 4s，滑杆 0.6–4s），自动跟随圆角，在控制面板外观分区内配置
- **控制面板**：统一管理账号、云同步、工作区、分类与外观；固定 `672×520` 尺寸，无滚动条（`no-scrollbar` 可滚但不显示）
- **深浅主题**：基于 `next-themes`，支持浅色 / 深色 / 跟随系统三档，外观分区内一键切换
- **首次使用引导**：仿 Windows OOBE 的分步引导（注册 → 建工作区 → 欢迎页）
- **云同步**：云端是唯一数据源——登录/启动先拉取云端装载，本地变更防抖推送，窗口重新聚焦自动「先推后拉」对齐多端

## 技术栈

| 层 | 选型 |
| --- | --- |

## 快速开始

### 1. 准备环境变量

在项目根目录创建 `.env.local`：

```bash
TURSO_DATABASE_URL=libsql://<your-db>.turso.io
TURSO_AUTH_TOKEN=<your-token>
```

数据库表结构会在首次请求时自动建好并迁移，无需手动执行 SQL。

### 2. 启动开发服务

```bash
npm install
npm run dev
```

打开 <http://localhost:3000>，注册一个账号即可开始使用。

### 3. 生产构建

```bash
npm run build
npm run start
```

## 同步机制概要

- 登录是进入主界面的唯一入口，云端（Turso）是唯一数据源，浏览器不再保存业务数据
- 登录/启动先**拉取云端**装载全部数据；升级自旧版本时会把浏览器里残留的 localStorage 数据做一次**并集迁移**（按 id 合并、冲突以云端为准），上传成功后清除本地残留
- 之后的每次变更经 1.2s 防抖推送到云端（全量快照）；切换工作区与手动同步都是「先推后拉」，并用请求序号丢弃乱序返回的旧响应
- 窗口重新可见/聚焦时（30s 节流）自动先推后拉，保证多端回到前台即对齐；对账失败期间推送被门控，绝不用空数据覆盖云端
